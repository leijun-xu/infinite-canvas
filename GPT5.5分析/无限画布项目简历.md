## 项目经历

### Infinite Canvas - 可操作浏览器画布的多模态 AI Agent

**个人开源项目 / 核心开发者** | [项目周期请填写]  
项目地址：<https://github.com/basketikun/infinite-canvas>

面向视觉创作场景的本地优先 AI 工作台。项目核心是将 Codex Agent 与浏览器中的 React 无限画布连接起来，使 Agent 能够理解当前画布状态，并通过结构化工具完成节点创建、内容修改、连线编排和多模态生成。

**技术栈**

Codex app-server、MCP SDK、JSON-RPC、SSE、Node.js、Express、Zod、React 19、TypeScript、Vite、Zustand、Ant Design、Tailwind CSS、IndexedDB、localforage、WebDAV、Docker

**Agent 架构与通信**

- 设计由 **Canvas Agent HTTP 主进程、Codex app-server 子进程、MCP Server 子进程**组成的三进程架构，将 Codex 推理能力、本地协议桥接和浏览器画布执行环境解耦。
- Canvas Agent 通过 `child_process` 启动并复用 `codex app-server --stdio`，使用 JSON-RPC 完成初始化、线程创建/恢复、模型查询、Skill 加载、turn 启动/中断和审批结果回传。
- 基于官方 MCP SDK 注册画布工具，并使用 Zod 定义与校验工具参数；Codex 作为 MCP Client 调用工具，MCP Server 再通过 HTTP 将请求转发给 Canvas Agent 主进程。
- 设计完整工具调用闭环：`Codex → MCP over stdio → Canvas Agent → SSE tool_call → 浏览器 applyOps → POST /canvas/result → MCP Promise 完成 → Codex`，解决 SSE 只能单向推送、浏览器执行结果必须异步回传的问题。
- 浏览器主动同步包含项目、节点、连线、选区和视口的结构化快照；Agent 读取的是受控快照而非 DOM，因此可以稳定执行 `add_node`、`update_node`、`connect_nodes`、`set_viewport` 等原子操作。
- 将 Codex 返回的 `thread.started`、`turn.started`、`item.*`、`turn.completed` 等事件转换为统一前端事件，通过 SSE 实时展示回复、推理摘要、计划、命令、文件修改、工具调用和 Token 消耗。
- 以 `threadId + turnId + itemId` 建立消息归属和去重规则，流式事件仅补充尚未物化的内容，历史快照落盘后成为权威数据，避免断线重连或页面刷新产生重复消息。
- 使用 `clientId`、`sessionStorage` 与 Web Locks API 隔离浏览器标签页，确保 Agent 工具调用只路由到对应画布客户端，并支持连接恢复和进行中事件重放。
- 实现工具二次确认、Codex 权限审批、任务中断和操作前快照，使 Agent 写入画布的行为可审核、可拒绝、可撤销。
- 将连接 Token、Origin 白名单和本地监听地址组合为安全边界；服务默认绑定 `127.0.0.1`，配置目录与文件使用受限权限，并对日志中的常见凭据和图片 Data URL 脱敏。
- 支持图片附件经浏览器上传至 Canvas Agent，临时写入本地后作为 `localImage` 输入交给 Codex，使 Agent 能在同一 turn 中理解用户文字、上传图片与画布引用。

**Agent 实现的产品能力**

- 在浏览器侧边栏直接创建、恢复和归档 Codex 会话，切换模型、推理强度和权限模式，并查看流式回复、任务计划、工具过程、审批与诊断日志。
- 允许 Codex 读取当前画布及选中内容，批量创建或更新文本、图片、视频、音频、配置节点，自动排列节点、建立连线、调整视口并触发文本或多模态生成。
- 支持在对话中通过 `@` 引用画布素材、通过 `/` 选择本地 Skill，并在刷新或重启后恢复附件、Skill、画布引用和本地预览。
- 提供 Codex App 插件，自动注册 MCP、启动本地 Agent、读取连接信息并打开目标画布，降低用户配置和接入成本。

**画布与工程能力**

- 基于 React 19 与 Zustand 实现无限画布，支持平移缩放、节点拖拽与缩放、多选、分组、连线、小地图、撤销重做和导入导出；文本、图片、视频、音频及生成配置节点可组合为多模态工作流。
- 封装 OpenAI / Gemini 兼容调用层，支持文生图、参考图编辑、文本/视频/音频生成、多渠道配置、异步任务轮询、请求取消与自定义调用脚本。
- 使用 IndexedDB 与 localforage 分离存储结构化元数据和媒体 Blob，实现 WebP 缩略图缓存、按需原图加载、无效资源清理及 WebDAV 跨设备增量同步。
- 构建动态 ESM 节点插件体系与 TypeScript SDK，支持插件安装、更新、启停、节点注册、宿主 React Runtime、私有存储和工具栏扩展。

**项目亮点**

- **Agent Runtime 复用**：没有重复实现推理循环，而是直接复用 Codex app-server 的线程、工具、Skill 和审批能力，项目聚焦于协议适配与业务执行。
- **Agent 与 UI 解耦**：Codex 只调用结构化 MCP 工具，浏览器仍是画布状态的唯一执行者，避免依赖坐标和 DOM 的脆弱自动化。
- **跨协议异步闭环**：组合 JSON-RPC、MCP、SSE 与 HTTP 回调，让本地 Agent 能够等待浏览器完成真实操作并获得确定结果。
- **可控的 AI 写操作**：工具输入经过 Schema 校验，操作经过客户端路由和可选人工确认，执行前保留快照，兼顾自动化效率与可恢复性。
- **复杂状态一致性**：统一处理流式增量、历史快照、线程恢复、多标签页隔离和进行中事件重放，避免消息串线与重复渲染。
- **本地优先与安全边界**：AI 凭据和画布数据主要保留在用户设备，本地 Agent 仅监听回环地址，并通过 Token、Origin 和文件权限限制访问。
